Item 2: capture group 1 only in the renaming shapes

  colspec.rs: expand and expand_bases share a private select(.., with_groups). expand
  (output selection, filters, plain maps) no longer looks at capture groups at all, so a
  group that does not take part (+(x)?num\d) is no longer an error outside renaming;
  before, expand went through expand_bases and refused it everywhere. expand_bases is
  unchanged and still refuses an empty or non-participating group, now only for renaming
  computes.

  compute.rs: the per-column loop asks for groups only when the compute has a Rename
  (P/SPEC/S, SPEC/S, P/SPEC/, /SPEC/, P//SPEC//S). The empty Rename that stood in for a
  group-named column without delimiters is gone: without delimiters the target is the
  column's own name, i.e. the plain map with its -i rule. /+(fib)/ (group equal to the
  name) stays the in-place case of a renaming compute and needs -i.

  Tests: o.rename-group reworked: the group cases moved to slashed forms; new cases for
  -i +num(\d) (in place), -i +(num|fib)\d (alternation), +(x)?num\d as output columns
  and as an -i map; +num(\d)::.. without -i is now the "already exists" error. Unit test
  colspec::capture_groups. Manual section 6 (paragraph and example now /+(k)g/), 14.3
  (new entry), guidelines.txt and the help text.

Item 5: doccheck.py --update, make docupdate

  examples() also returns where the expected lines of each command are in the document
  (0-based start and end, after trailing blank lines are dropped; with no expected lines
  start is the line of the next command or the closing fence) and the fence's indent.
  check() with update collects (start, end, indent, lines) for each example whose stdout
  does not match; main() applies them bottom-up, so earlier positions stay valid, and
  calls docalign.align_document on the document (imported; python3 -B so that no
  __pycache__ appears, as with optcheck).

  refill(): '...' keeps the count of lines shown before the first and after the last
  '...' (one '...' in the result; all actual lines if they are not more than those);
  'pluk:' lines stay as written, each after as many new lines as preceded it before. A
  stderr mismatch stays a failure: messages are not rewritten (decision 5). With 2>&1
  everything is stdout and rewritten.

  Guard, added after a trial: an example whose stdout is now empty while output was
  shown is reported and not rewritten. Without it a missing data file wiped the output
  of every example of a document.

  Targets: docupdate in pluk/Makefile builds pluk (as test does) and runs docupdate in
  test/Makefile; the workflow is in the comment there. Tried on a scratch copy of
  README.md with the aln_nedit_pia example changed (output rewritten and aligned; the
  other examples untouched); README.md itself is left for the user's rewrite. Tested by
  hand on a scratch document: plain output, '...', a stale 'pluk:' line (reported), 2>&1,
  a continued command, an indented fence, an example without output, a matching one.


Item 6: option reference (manual section 15)

  New section 15, one entry per option, '- `OPTION`: short text (section N)', in the
  order of pluk --help. The help's long Options group is split under subheadings that
  keep that order (header, columns and output; filters and other output files; SAM and
  BAM; column lists, quantiles, state, progress); then Computes, Dictionaries, Listings
  and help. The section of each entry was found by a script (where the option occurs,
  outside sections 14 and 15) and chosen by hand. References are plain 'section N', so
  doccheck.py checks them. The operator reference is now section 16; the 16 references
  to section 15 were renumbered (opscheck.py does not depend on the number).

  optcheck.py: finds the section by its title ('## N. Option reference'), reads each
  entry's leading code spans (several allowed: `-H`, `--help`:) and applies the same word
  and stem rules as to the help text. --strict fails on an option of pluk --help without
  an entry and on an entry option pluk does not have (both tried on a scratch copy). The
  former check (a mention anywhere in the manual) is gone.
