Item 1: extension (--sam-aln-context, --sam-aln-xy) and the context in the view

  sam.rs: extend(pos, cigar, reflen, options) returns the new POS and CIGAR and the number
  of operations written at each end (the context), or None if nothing changes. The clips
  are found first: leading H, then S; trailing H, then S; the middle of the CIGAR is
  copied as written (no re-serialisation, so its text stays exactly the input's). side()
  computes one end: shared x = min(reference clip, soft clip, budget), then d from the
  remaining reference clip or i from the remaining soft clip (only one of the two can be
  non-zero: if both clips remain after x, the budget is used up), and the soft clip left.
  Order of the written operations as pick: 5' [H] S I D X, 3' X D I S [H]. The reference
  clip at the right uses the input POS and CIGAR (pick: computed before the left side
  changes POS) and is clamped at 0 for an alignment past the reference end.

  ContextOptions::budgets: N at each end; with xy, max(N, POS - X) at the left if X < POS
  and max(N, Y - ref_posy) at the right if Y > ref_posy (ref_posy = POS + reference length
  of the CIGAR - 1, trails included, as pick's narrow uses it).

  The context is recorded as operation counts at each end, including the hard and soft
  clips written there; they are trail operations anyway, so including them is harmless
  and keeps the count a plain prefix length. trails(ops, context) takes the context
  operations first and then continues with the trail letters; is_context(i, n, context)
  tells draw (a context X is drawn as '.') and posinfo (skipped) which operations are
  context. View::context is set by main.rs for every row while the extension is active
  (as View::query); Machine::run's reset does not touch it.

  main.rs: Stages::judge runs the extension after the normal form, on mapped records with a
  POS; the reference length comes from View::reference_length (seqlen). Records whose right
  side had a budget but no reference length are counted and reported at the end.

  aln_nedit_pia and aln_nedit_piu now count the edit columns (x - ~, and = for piu) instead
  of subtracting the good ones (decision 3). This changes step18's values where pick

  Options: --sam-aln-context=N (digits only), --sam-aln-xy=X,Y (opt::parse_xy, also for
