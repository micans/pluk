Step 35 notes: option renames. Background: plan/OPTIONS-naming.notes.txt (collation and
brainstorm), plan/zz-notes.txt (-% and -%%, the model for reserved names).

General. Old names are not silent no-ops and not aliases: each gives an error naming its
replacement, at least until release. -e and -E stay reserved after that (grep, sed and
perl users expect "expression" and "extended regex" there).

Item 1.
  -w (was -e): diff -w, "ignore all white space", is an exact precedent; grep -w (whole
    words) is the only rival meaning, and pluk has no word matching.
  -C<N> (was -E<N>): pairs with -c as -K with -k: -c writes the count, -C<N> requires
    it. grep -C (context lines) has no pluk equivalent. -#<N> was considered (more
    idiosyncratic).
  Messages: "-e: reserved; use -w to remove white space", "-E: reserved; use -C<N> for
    the number of output rows"; also inside a bundle (-ke).
  The unknown-option example of the tests was -kw; it is now -kj.

Item 2.
  -p (was -U): "preserve order", as cp -p; lower case, as it has no partner. -I was
    ruled out: -i/-I would be an unrelated pair. -U: error naming -p.
  -H: output a header line, also with -k. It is the header half of -K: -K is -kH (the
    Config field big_k became header). -h takes precedence, as over -K before; -c
    concerns stdout as before. -H no longer prints help (pick: it does): help is
    --help only; the usage note of pluk without arguments already names --help. A pick
    user typing -H gets the normal output (with a header line), which was judged
    acceptable; no special case for -H as a word of its own.
  Tests: o.help now checks that -H alone is a normal run (no columns: usage note,
    exit 1); o.help-bundle (-kH was an error) is replaced by o.header-H.

Item 3.
  --after=NAME (was --A=NAME): reads "insert after NAME"; a long option named by one
    capital letter was unusual. -A<N> stays.
  --rejected=FILE (was --other), --assert-failed=FILE (was --assert-other): each says
    what goes into the file.
  Old names: errors naming the replacement ("--other: use --rejected=FILE").
  Only the option names changed; the identifiers in the code (config.other,
    assert_other, insert_after) and the test names (o.other*, o.assert-other*) are
    kept. Messages name the new options.
  Dictionaries: help, manual section 7 and the option reference lead with --kdict-
    --fdict- --cdict- --tdict (and --fasta-dict); --kd- --fd- --cd- --td are short
    forms. The examples keep the short forms (the manual says so).

Item 4.
  SAM alignment options form one family, --sam-aln-*: --sam-aln-mark (was -mrk; the
    user chose mark over markers), --sam-aln-extend (was --sam-aln-xy),
    --sam-aln-narrow (was --sam-narrow-xy, which lacked the aln- part). --sam-aln-prefix
    and --sam-aln-context are unchanged.
  --sam-header (also /FILE): no clash with -h (which drops the header), still reads as
    samtools view -h. --sam-h stays as a synonym (also --sam-h/FILE): first made an
    error, then reinstated on the user's request (short to type, and pick's name).
    Help, messages and the manual name --sam-header first.
  --sam-qual-simple (was --sam-qlt-sim), --sam-rbt-region (rbt names the rbt_
    operators). --sam-rbt stays as a synonym: first made an error, then reinstated on
    the user's request, as it meshes with the sam_rbt operator. A message names the
    spelling given (--sam-rbt=X,Y: X is larger than Y).
  --sam-nonf is kept (user's choice), with --sam-keep-flanks as a synonym; the help
    lists both on one entry. --sam-ND-adjust is unchanged (CIGAR operations N and D).
  The other old names give an error naming the replacement. The Config
    fields (sam_h, sam_aln_mrk, sam_qlt_sim, sam_aln_xy, sam_narrow_xy, sam_rbt) keep
    their names, as in item 3.
  Test o.sam-renamed: the old names, --sam-keep-flanks against --sam-nonf, --sam-h
    (and /FILE) against --sam-header, and --sam-rbt against --sam-rbt-region. The
    other changed refs differ only by the new names (checked by applying the rename
    to the old refs).
  Line width: the manual and guidelines already have many lines over 90 columns, so
    lines lengthened by the longer names were not rewrapped.
